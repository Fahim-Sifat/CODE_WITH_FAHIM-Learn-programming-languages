HTML Emojis



In HTML, you can add emojis in several ways! 🌟



🧩 1. Directly using emojis:

You can just paste an emoji character directly into your HTML code:

<p>Hello 😄 Welcome to my website!</p>


-✅ Works in most modern browsers.
-⚠️ Make sure your HTML file uses UTF-8 encoding:

<meta charset="UTF-8">

🔢 2. Using HTML entity codes: >

Each emoji has a Unicode code point, which you can represent using:

Decimal: 😀

Hexadecimal: 😀

Example:

<p>Hello 😀 Welcome!</p>
<p>Hello 😀 Welcome!</p>


Both render as:

👉 Hello 😀 Welcome!



🎨 Common emoji codes:

Emoji Description Decimal code Hex code
😀 Grinning face &#128512; &#x1F600;
😂 Face with tears of joy &#128514; &#x1F602;
❤️ Red heart &#10084; &#x2764;
👍 Thumbs up &#128077; &#x1F44D;
🎉 Party popper &#127881; &#x1F389;
🔥 Fire &#128293; &#x1F525;
